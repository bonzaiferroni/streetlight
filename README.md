## API Reference

The API reference is generated by Dokka and published at [bonzaiferroni.github.io/streetlight](https://bonzaiferroni.github.io/streetlight/).

## Modules

| Module | Description |
|---|---|
| [`kampfire`](kampfire/README.md) | Utilities and types for apps that talk to a server, shared by client and server. |
| [`koala`](koala/README.md) | The base components and functionality for web apps. |
| [`model`](model/README.md) | The domain types and API endpoints shared by the server and the clients. |
| [`web`](web/README.md) | The web client: the pages the server renders, and the views the browser builds over them. |
| [`compose`](compose/README.md) | The native app, built with Compose Multiplatform. |
| [`server`](server/README.md) | The Ktor server of the pages, the API and the webhooks. |
| [`daemon`](daemon/README.md) | A standalone process that runs the crawler beside the server. |
| [`tools/leadExtension`](tools/leadExtension/README.md) | A browser extension that sends the page in view to Streetlight as a lead. |
| [`tools/promo`](tools/promo/README.md) | The capture pipeline for promo videos. |
| [`tools/svg`](tools/svg/README.md) | The workshop for the site's icons. |
