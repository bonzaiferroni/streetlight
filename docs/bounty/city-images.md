# City Images

Find a reusable image for each city in the database, credited to its author, and set it through the API. The image URLs below are kept for setting the same images on the production server.

## Method

* Source: the lead image of the city's English Wikipedia article, or the first of its other photographs that passes the checks, read from Wikimedia Commons.
* Checks: a license of CC BY, CC BY-SA, CC0 or public domain; a named author; at least 800px wide; not a map, seal, flag, logo or drawing.
* Attribution: `attribution` is the author and license, as "Author, CC BY-SA 4.0"; `attributionUrl` is the file's Commons page.
* Setting: the image is uploaded through `Api.Users.UploadImage` with its metadata as a form field, then set on the city with `Api.Cities.UpdateCity`, keeping the city's name, description and links.
* Account: `leadline`, a registered account made for this bounty.

## Steps

1. 🍻 Count the cities without an image: 95 of 96.
2. 🍻 Gather a candidate for each city and review them.
3. 🍻 Upload and set the images.
4. 🍻 Record each city's image here.

## Findings

* `provisionImageAndStore` stores an image downloaded from an absolute URL without its metadata, so an image set by URL loses its attribution. The upload path keeps it.
* The browser's `uploadBlob` appends the metadata as a `Blob`, which arrives as a file part rather than a form field, so the server never reads it and an upload from the UI carries no attribution.
* Wikimedia throttles downloads with `429 Too many requests` after a few dozen in quick succession, and harder for originals. A run takes the standard thumbnail sizes above and waits 15 seconds between images.
